# ぬりけし

画像の一部を、選んだ色で塗りつぶして消す——それだけのアプリ。

AI による自動削除ではなく、昔ながらの「消しゴム(マスキング)ツール」だけを提供します。
画像はすべて端末内(ブラウザ内)で処理され、サーバーには一切送信されません。

## 機能

- 丸 / 四角のペン先、サイズ変更(2〜120px)
- カラーピッカー + 黒/白クイックスワッチ + スポイト(画像から色を拾う)
- Undo / Redo(10 回まで)
- 1本指で塗り、2本指でピンチズーム / パン(PC はマウスホイールでズーム)
- 保存は共有シート経由(iOS/Android)またはダウンロード。JPEG は JPEG、それ以外は PNG で出力
- PWA 対応: ホーム画面に追加すればオフラインでも動作

## 使い方(スマホ)

1. ブラウザで公開 URL を開く
2. iPhone: 共有ボタン →「ホーム画面に追加」/ Android: 「アプリをインストール」
3. 「開く」でカメラロールから画像を選び、塗って、「保存」

## 開発

ビルド不要。静的ファイルのみ。

```
python -m http.server 8000
# → http://localhost:8000
```

調整用定数は `app.js` 冒頭(`MAX_DIM`: 読み込み時の最大長辺、`MAX_HISTORY`: Undo 回数)。
